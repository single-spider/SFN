## Intended use and limitations

This dataset supports software-only training, validation, or regression checks for the stated split and backend. Labels are generated by simulation rather than human annotation. It is not evidence of real-camera performance. The clean release datasets are deliberately small release fixtures; the larger randomized datasets remain the training evidence for the final perception checkpoints. The Panda dataset uses the disclosed synthetic high-contrast appearance and does not represent metallic, reflective, or uncontrolled real workpieces.
